01 / INTRODUCTION

What is Encapsulation?

Encapsulation is one of the four fundamental principles of Object-Oriented Programming (OOP).

It is the process of combining data (variables) and methods (functions) into a single unit called a class.

It also helps control access to data and prevents accidental modification of important information.

Simple Definition: Encapsulation means wrapping data and methods together inside a class and controlling access to that data.

Without Encapsulation

Data can be modified directly, which may lead to incorrect or unexpected values. 

balance = 5000
balance = -10000

print(balance)
Output: -10000

With Encapsulation

Data is controlled through methods that validate the values before changing them. 

class Account:
    def __init__(self):
        self.__balance = 5000

    def deposit(self, amount):
        if amount > 0:
            self.__balance += amount
Data is controlled!

02 / ACCESS CONTROL

Access Types in Python

Python uses three naming conventions for attributes.

01

Public

self.name

Public variables can be accessed from inside and outside the class. 

class Student:
    def __init__(self):
        self.name = "Chandini"

s = Student()
print(s.name)
Output: Chandini
02

Protected

self._name

A single underscore indicates that a variable is intended for internal use and subclasses. 

class Student:
    def __init__(self):
        self._marks = 90

s = Student()
print(s._marks)
Output: 90

Note: This is a convention, not strict access protection.

03

Private

self.__name

Double underscore triggers name mangling. It discourages direct access from outside. 

class Student:
    def __init__(self):
        self.__marks = 95

    def show(self):
        return self.__marks

s = Student()
print(s.show())
Output: 95

03 / PRACTICAL EXAMPLES

How Encapsulation Works

Example 1: Getter and Setter Methods

A getter method retrieves private data. A setter method modifies private data after validation. 

class Employee:

    def __init__(self, salary):
        self.__salary = salary

    # Getter
    def get_salary(self):
        return self.__salary

    # Setter
    def set_salary(self, salary):
        if salary > 0:
            self.__salary = salary
        else:
            print("Invalid Salary")


emp = Employee(30000)

print(emp.get_salary())

emp.set_salary(40000)

print(emp.get_salary())
Output:

30000

40000

Example 2: Bank Account

The account balance is private. Users can deposit and withdraw money using methods. 

class BankAccount:

    def __init__(self, balance):
        self.__balance = balance

    def deposit(self, amount):
        if amount > 0:
            self.__balance += amount
            print("Deposit Successful")
        else:
            print("Invalid Amount")

    def withdraw(self, amount):
        if 0 < amount <= self.__balance:
            self.__balance -= amount
            print("Withdrawal Successful")
        else:
            print("Insufficient Balance")

    def get_balance(self):
        return self.__balance


account = BankAccount(10000)

account.deposit(2000)
account.withdraw(3000)

print("Balance:", account.get_balance())
Output:

Deposit Successful

Withdrawal Successful

Balance: 9000

Example 3: Name Mangling

Python internally changes the name of a double-underscore attribute to include the class name. 

class Student:

    def __init__(self):
        self.__name = "Chandini"


s = Student()

# Direct access raises AttributeError
# print(s.__name)

# Name-mangled access
print(s._Student__name)
Output:

Chandini

Important: Name mangling does not make data completely private. It mainly prevents accidental access and name conflicts in subclasses.

05 / INTERVIEW PREPARATION

Important Questions

1. What is Encapsulation?

Encapsulation is an OOP principle that combines data and methods into a class and controls access to the data.

2. What are the access modifiers in Python?

Public, protected and private are the three commonly used access conventions in Python.

3. What is a getter method?

A getter method is used to retrieve the value of an attribute.

4. What is a setter method?

A setter method is used to modify an attribute, often after validating the new value.

5. Does Python support private variables?

Python supports name mangling using double underscores, but it does not provide strict private access control.

6. What is the difference between _name and __name?

A single underscore indicates an internal-use convention. A double underscore triggers name mangling.
